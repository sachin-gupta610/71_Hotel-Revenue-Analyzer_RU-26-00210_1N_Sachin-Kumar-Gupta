# Hotel Revenue Analyzer (PS No. 71)

A Python program using Pandas and Matplotlib to analyse hotel room sales data from `hotel_sales.csv`, calculate daily revenue, identify the best-performing day, compute revenue share by room type, and visualize results with charts.

## Features
- Validates and skips rows with negative or non-numeric values.
- Displays daily revenue, total revenue, and best day with a bar chart.
- Displays revenue share by room type with percentages and a pie chart.
